IMPLEMENTATION

Methodology

Summary of the implemented machine learning classification pipeline.

01

Development Data

The cleaned development dataset contained 1,166 spirometry records and 12 predictor variables.

02

Missing Values

Median imputation was fitted using development data and applied through the saved preprocessing pipeline.

03

Class Balancing

Random undersampling was restricted to training data to balance obstructive and non-obstructive observations.

04

Cross-Validation

Five-fold stratified cross-validation was used to generate out-of-fold model predictions.

05

Base Learners

Random Forest, SVM, XGBoost and MLP were trained as the four individual classifiers.

06

Stacking

Logistic Regression combined the out-of-fold probability outputs of the four base learners.

07

Independent Validation

The completed models were evaluated on 154 records that were not used during model development.

08

Deployment

The complete preprocessing and ensemble pipeline was serialized and integrated into this Flask application.
